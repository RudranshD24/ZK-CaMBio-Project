| D-010 | 2026-09-30 | Fingerprint Preprocessing V2 and Encoder Choice: Selected Preprocessing V2 (fixed physical scale factor per DB, foreground centroid centering, tighter DB2 platen window excluding slanted border bars, constant pad 255) and Baseline B (FingerResNet18 fine-tuned with CosFace margin loss + extra training data, 256-d output embedding). Fixed scale justification: Same sensor = same physical resolution; dynamic bounding box scaling destroyed spatial ridge frequency across impressions. DB1 (raw 640x480): 384x384 window (scale 0.333) fits ~350-380px typical print without boundary cuts or magnification. DB2 (raw 328x364): horizontal window 256 centered at x=164 (42<=x<=286) strictly excludes slanted trapezoid platen edges and padding bars (scale 0.50). DB3 (raw 300x480 thermal): 384x384 window (scale 0.333) centered at x=150 and vertical centroid accommodates full sweep. Model selection strictly on 30 validation fingers (10/DB, same-DB impostors): (1) Gabor V1: Val Sep=0.0089, Val EER=47.65%; (2) Gabor V2: Val Sep=0.0129, Val EER=44.01%; (3) ResNet18 V1 (150 fit): Val Sep=0.6282, Val EER=6.48%; (4) ResNet18 V2 (150 fit): Val Sep=0.6322, Val EER=6.79%; (5) ResNet18 V2 + Extra Data (290 fingers: 150 fit + 100 DB4_A + 40 DB*_B, verified zero manifest overlap): Val Sep=0.6414, Val EER=5.49% (WINNER). Single test evaluation on 120 test subjects under Protocol D-009 (same-DB impostors): ResNet18 achieved 5.81% pooled EER (95% CI [4.72%, 7.15%]), Rank-1 fair gallery-40 accuracy 78.89% (DB1: 5.06% EER / 75.83% Rank-1; DB2: 8.50% EER / 75.00% Rank-1; DB3: 3.35% EER / 85.83% Rank-1). Gabor V2 achieved 41.10% pooled EER (95% CI [38.89%, 43.11%]), Rank-1 26.67% (DB1: 38.16% EER; DB2: 33.34% EER; DB3: 32.61% EER). | Preprocessing V1 resolved scale inconsistently and left trapezoid borders in DB2 (rejected: yielded 26.37% test EER with 37.04% DB2 EER). ResNet18 V2 without extra data (rejected: lower validation separation 0.6322 vs 0.6414). Baseline A Gabor (41.10% test EER; preserved as classical benchmark). |
